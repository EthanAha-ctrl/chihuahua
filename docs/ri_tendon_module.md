# RI20／RI30 绳驱实体装配研究

## 当前设计决策（2026-11-03）

用户要求减速机构采用 off-the-shelf。后续优先选厂家已经匹配并装配好的电机、减速器与轴承总成；RI20／RI30 暂不锁定。编码器和驱动器是否包含，按具体产品逐项确认。现有自定义 RI 总成与减速绳轮 CAD 保留作历史装配／空间研究，不作为当前采购或加工定案。

仍保留 1.5 kg 整机、每腿四个主动自由度和躯干集中驱动的目标；在整机质量、所需扭矩—转速、回驱阻力及绳载荷核算完成前，不宣称已找到满足全部要求的商品组合。成品减速器也不自动解决卷筒、绳端夹持、预紧和腿端接口的设计验证。

已发现的旧 CAD 绳端问题仍未修复：电机绕绳起点未接至夹持处，法兰拟用穿绳孔被夹紧螺钉占用，关节端末端止挡／夹持细节不完整；下文装配步骤表达设计意图，不能据此直接制造。

## 历史版本说明

本版把此前传动示意展开成可以逐件检查的 CAD。使用厂家原始 STEP 定子／转子，额外设计轴、轮毂、轴承座、绕线器和腿端连接。它是装配与空间评审稿；未达到加工图定版，也未证明 1.5 kg 整机预算闭合。

## 打开文件

`artifacts/ri_tendon_module/ri30_motor_module.step`、`ri20_motor_module.step`：两种完整电机机械总成，带绕线短绳。

`artifacts/ri_tendon_module/wood_leg_joint.step`：双槽输出轮、预紧端头、金属端帽、木杆和可选并联扭簧。

`artifacts/ri_tendon_module/complete_single_axis.step`：一只 RI30 总成、两根绳和一个木腿关节，按中位连接。

`artifacts/ri_tendon_module/abduction_cradle.step`：RI20 固定于躯干，以 6:1 绳轮驱动独立支撑的摇架，三个完整 RI30 机械总成随摇架转动。该视图检验空间代价，不代表已经放进四足整机。

以上可用 FreeCAD 或其他 STEP 查看器打开。STEP 保留实体和分件；对话内三维图使用同源三角化显示，做了网格简化和 0.02 mm 显示量化。制造尺寸以 CAD 实体及后续正式工程图为准。`artifacts/ri_tendon_module/components.json` 是零件清单和来源说明。

## 原厂件与自定义件

RI20 原厂：Ø25×14.5 mm，转子孔 Ø11.6；RI30 原厂：Ø38×14 mm，转子孔 Ø17。两个原厂文件均没有轴、轴承、壳体、绕线器、编码器。厂家 STEP 是简化电磁组件包络，不含细分绕组、槽和磁片；本模型没有虚构这些内部细节。

采购件包络：686ZZ 轴承 6×13×5 mm、紧固件、挡圈等。轴承内部的可视几何不能当成某品牌的制造图。电机端轴承以内圈、外圈和防尘盖分件显示；腿端为便于观察显示滚道及滚珠。

定制件：铝制定子座、定位端盖、阶梯钢轴、转子连接毂、隔套、双槽输出轮、预紧滑块、金属腿帽和外展摇架。编码器、磁体和扭簧仅为占位几何，尚未完成型号／参数选择。

## 电机总成的装配顺序

1. 加工定子座、前后盖和定位面。定子外圆通过受控胶层固定到铝座，导热与扭矩由该接口传入机架。引线从实物对应的开口引出；RI30 官方模型引线在归一化 Z=13..14 mm 一侧。
2. 把原厂转子环胶合到连接毂。RI30 连接毂外径暂取16.9 mm，RI20取11.5 mm，胶层及间隙须与厂家及胶材确认。
3. 从轴的后端装入转子连接毂和中间隔套，连接毂与轴的固定／同轴固化需要工装。卷筒与轴是一体钢件：轴承段Ø6，绳中心节径Ø6，绳槽底约Ø5.16。卷筒没有Ø6贯穿套装孔。
4. 装后轴承及后侧隔套和薄锁母，把旋转组件放入已装定子的座内。夹紧力经过轴承内圈和隔套，保持转子不接触定子；实际气隙、同轴度及轴向位置需实测。
5. 装前轴承、定距柱和前桥盖。柱端小止口与座孔负责位置，M2长螺钉负责夹紧。两个轴承把绳拉力引入壳体；前轴承外圈的热伸长间隙仍需公差设计。
6. 每根绳分别装在自己的螺旋槽。两槽旋向相反；0.8 mm绳、1 mm槽距、每槽4.5圈，中位约3圈。输出±60°对应8:1电机±1⅓圈，名义存绳范围约1⅔..4⅓圈，未验证全过程偏角、槽口接触和端头滑移。
7. 绳端穿过端法兰的孔，以独立小压块锁住，保留死圈。压块尺度很小，必须先做夹持和绕卷试样，不能仅凭绳的直线破断拉力判定可用。
8. 装轴端磁体、固定编码板及隔柱。实际传感器、气隙、磁场干扰和换相零位尚需确定；电机编码器测量不包含远端绳伸长。

## 关节与木杆装配

1. 后叉耳、后轴承和桥板先固定到上一级结构。
2. 输出轴穿过轴承；装镂空双槽轮和横向传矩销。两槽的绳中心半径均为24 mm，轴向中心相隔6 mm，外径48.8 mm。
3. 输出轮螺接金属腿帽；木杆进入端帽槽腔。连杆两轴中心距65 mm，对应本稿木材净长43 mm、截面5×7 mm。胶接与贯穿夹紧螺钉共同构成待验证接口。
4. 每根绳末端进入独立夹持滑块。转动M2螺杆调整长度，锁紧螺母保持位置；两个端头同步调短增加共同预紧，差动调节改变零位。图中短尾与槽之间有轴向过渡，该位置的弯曲和摩擦尚需打样。
5. 若装并联扭簧，固定簧脚挂入固定耳，移动簧脚挂入输出轮／腿帽一侧，再装前耳、前轴承和挡圈。扭簧用于储能和助力，绳索预紧仍由锁定的调节螺杆设置；扭簧刚度和预扭角未定。

## 外展轴

外展也用双向绳驱。RI20固定在躯干，绳中心r3输入驱动R18输出轮（几何比6:1）。输出轴由自身两只轴承支撑，带动摇架；三个RI30和后续导向件随摇架转动，避免主腿绳路跨越外展轴。图中三个完整电机总成按真实包络布置，摇架、抱箍和支臂都占空间。

本稿完整RI机械总成轴向约53 mm，远大于14 mm裸电机；四套完整外展摇架的空间、质量和惯量尚未集成通过。下一轮需围绕共用轴承壁、共用机架、轮盘减重及电机选型重新核算。

本版单腿外展支承本身的包络约162.5×111.5×99.3 mm，空间代价很大。三电机抱箍及摇架均为实际实体；目前没有证明四套能够布置在目标整机内。

## 本版检查与明确边界

- CAD实体有效性检查、STEP导出及三维显示同源检查。
- RI30的33个非绳零件、RI20的36个非绳零件，经精确实体交集检查，均未发现超过0.3 mm³的干涉；各自含引线／编码板的包络为45×47.5×52.9 mm和32×33×52.9 mm。记录见 `artifacts/ri_tendon_module/motor_validation.json`。
- 腿端43件的包围盒重叠候选逐对做实体交集，未发现超过0.3 mm³的干涉；这不能代替装配公差、运动碰撞或弹性变形校核。
- 外展49组支承实体对检查时已导出的完整电机STEP未发现超过0.01 mm³的交集；未执行支承内部所有配合的全对全检查。该静态检查不包含外展运动扫掠和绳路运动。
- 轮盘体积约15,785 mm³；若用密度2.7 g/cm³的铝，约42.6 g，明显偏重。不能称本版已实现低质量目标。
- 绳路只表达中位装配；没有求解全行程自动排绳、绳伸长、瞬时张力、冲击、木材屈曲、强度或热平衡。
- 螺纹按名义包络显示；外展的若干固定接口、紧固工艺及传感器包络仍需要详细出图。本版不应直接交付加工。

## 来源与重建

官方文件、下载地址、图纸公差和SHA-256见 `vendor/README.md` 与 `vendor/sources.json`。

重建：在仓库根目录执行 `uv run --with cadquery --with trimesh --with fast-simplification python -m src.components.z_common.tendon.build_cad`。依赖 CadQuery 2.8、OpenCascade 7.9、trimesh、fast-simplification。原厂几何未缩放；本版只增加自定义装配件。

## Repository layout and commands

Run from the repository root. Source code: `src/components/z_common/tendon/`.
Manufacturer drawings: `vendor/components/motor/` (including `sources.json`).
Generated STEP, geometry, screenshots and review bundles: `artifacts/ri_tendon_module/`.

```bash
uv run --with cadquery --with trimesh --with fast-simplification python -m src.components.z_common.tendon.build_cad
uv run python -m src.components.z_common.tendon.publish_view --renderer /absolute/path/to/render.py
```

The publisher requires an explicit renderer and all listed validation artifacts;
missing inputs are errors. CAD rebuild was verified with the command above;
the obsolete local CAD environment has been removed.
