统一 `viewer.py` 只负责读取、调用上游工具和显示。 
三种格式可以共用 PyVista 显示层。
原始坐标、单位、帧序和置信度应保留；
视角通过相机调整。

retarget 在 `d1_prepare_dataset` 中完成，输出适配本机机器人结构的参考运动。
`d2_labelled_training` 接收这些参考运动，负责物理跟踪教师训练与局部目标条件策略蒸馏。
