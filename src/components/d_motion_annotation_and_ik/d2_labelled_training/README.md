动捕里没有“咬住球”，符合这套设计的前提。咬球能力由后续任务训练产生：

```
d2：运动数据 → 学会身体协调，以及如何响应局部部位目标
                            ↓ 初始化同一个策略

```

d2 可以从头部运动构造局部目标，学习“头要到这里，身体怎样配合”。嘴部开合、球的接触和有效夹持没有示范，就不能算作已经学会。

你负责重定向，我来处理训练代码的衔接。

“建立训练环境”具体就是把机器人包装成可反复执行的接口：

- `reset`：设置机器人、参考片段和初始状态。
- `step`：接收关节位置目标，执行 PD 与仿真，返回状态、奖励和终止信息。
- 明确每个动作元素对应哪个关节，以及控制周期、PD 增益和力矩限幅。

关节顺序和执行器参数应尽量读取现有模型；需要我们确定的是训练如何使用它们。环境全部放在 d，`b` 不动。

手柄恰好是局部目标接口的人工输入端:

```
摇杆／按键 → 指定脚端的目标位置与时间变化
                        ↓
              局部目标 + commanded mask
                        ↓
           策略协调全身 → 关节位置目标
```

训练时，从完整运动里保留某几只脚的目标，让策略学习其余身体怎样配合；操作时，由手柄提供这些目标。

手柄没有指定的关节保持自由，由策略协调。这正好承接 MaskedMimic 的局部条件机制，也保留了我们已确认的四肢操作方式。
