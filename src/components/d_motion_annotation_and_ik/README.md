# Human motion annotation and IK

局部任务目标 lower 为机器人在当前物理状态下的全身控制动作。

高层目标描述指定身体部位应完成的运动与接触关系。例如，嘴接近并持续咬住球，或者一侧后脚在身体指定区域进行往复接触。起跳、下蹲、重心转移和支撑方式由策略自主学习，高层接口不设置这些动作类别。

```
局部任务目标 ＋ 机器人状态 ＋ 目标对象与接触状态
                         ↓
                 目标条件全身控制策略
                         ↓
                  关节位置控制目标
                         ↓
          PD：结合实际关节位置、速度计算力矩
                         ↓
                  执行器力矩限幅
                         ↓
                  b：MuJoCo 执行
                         ↓
              更新机器人、对象与接触状态
                         └────────→ 下一控制周期
```

局部任务目标是 source code：它描述用户要求实现的效果，尚未规定全身如何完成。它需要表达以下信息：

- 作用部位：嘴、指定脚端或其他受控身体部位。
- 目标对象或区域：需要咬住的球、需要挠的身体区域，以及相对关系所使用的参考坐标系。
- 运动与时间条件：需要形成的相对运动，以及往复幅度、频率、持续时间等相关参数。
- 接触与开合条件：嘴部开合、接触、夹持，以及需要维持的时间。

球的实时位置和速度来自环境状态；身体上的目标区域随身体运动更新。目标描述通过这些对象建立相对关系，无须预先规定全身轨迹。

全身协调与物理控制由目标条件策略共同完成。

策略读取局部目标、目标的时间进展和实际状态，输出全部受控关节的位置控制目标。

关节限位、碰撞与摩擦由物理模型描述；执行器力矩限制由控制层与仿真模型一致执行。训练中的惩罚项用于引导策略，实际约束的执行与违反情况仍需明确检查和记录。

MuJoCo 根据施加的力矩、重力与接触计算实际运动。关节位置目标是产生驱动力的控制量；实际关节姿态由闭环动力学决定，两者之间可以存在产生所需力矩的偏差。

当WBC searching space 太大 收敛慢的时候,  使用 Scuf Omega Wireless PlayStation joystick 进行人工控制与动作标注。
`手柄运动目标 → 步态与接触阶段协调 → 全身运动求解 → 平衡与力矩控制 → other down stream components` 

---

把外部运动经验训练进一个接受局部目标、输出我们机器人关节目标的“小脑”，再让它在真实接触动力学中学习任务。

1. prepare dataset. 提供“身体怎样协调”，不要求数据里已经有咬球。优先使用狗动捕、已有四足运动。重定向后，在 MuJoCo 环境中执行并获得有效控制经验。数据中缺失的嘴部、趾部或接触标签明确标为缺失，交由后续任务训练补充. 最终需要的经验包含：

```
局部目标、机器人状态、对象状态、实际控制命令、下一状态、接触结果
```


2. 小脑采用一个统一的目标条件策略，复用已有的预训练机制。

```
局部目标编码＋机器人与对象的状态历史
                    ↓
             全身控制网络
                    ↓
          我们机器人各关节的位置目标
```

用完整运动训练物理控制教师，再随机隐藏部分身体目标，将教师的控制经验蒸馏到这个网络。这样，“只给嘴或某只脚目标，其他关节怎样配合”可以从已有运动中学习。这里直接复用 [MaskedMimic 的教师与局部条件蒸馏机制](https://arxiv.org/html/2409.14393v1)。

3. 预训练完成后，任务奖励决定如何使用和改变这些能力。

咬球训练评价真实夹持与持续保持；挠痒痒训练评价目标区域内的往复接触。整个控制网络允许继续更新，不把身体动作锁在预训练样本中。

最需要我们自己完成的工程是任务成功判定。例如嘴碰到球、把球推走、球被身体压住，都可能获得错误的“接近”奖励。必须通过指定夹持面的接触、口球相对运动和保持时间定义成功。运动先验无法替代这个定义。

4. 外部 rollout 用来改善经验质量，具体用途服从训练算法。

以成熟的 PPO 训练实现为基础：教师记录用于行为克隆初始化、困难状态初始化和人工纠正；策略更新使用当前策略在 d 管理的 MuJoCo 环境中产生的 rollout。这些状态转移同时可以进入世界模型的 replay buffer。

SuperMimic 的可微世界模型训练可以复用到这里，用于降低后续采样与优化成本。但接触模型必须能正确预测“夹持、滑脱、释放”；否则更快的模型 rollout 会扩大错误经验。[SuperMimic 的训练机制](https://arxiv.org/pdf/2610.28480)

这套组合的实际作用是：狗的运动数据提供协调经验，局部条件预训练提供可调用的控制能力，任务 RL 获得交互技能，人工标注补充难以探索的经验，世界模型提高经验利用率。

适配工作的交付物因此很具体：本机数据转换器、统一目标与动作接口、预训练后的控制网络、可信的任务成功判定，以及可追溯的物理 rollout。 已冻结的运行链无需增加其他控制路线。
